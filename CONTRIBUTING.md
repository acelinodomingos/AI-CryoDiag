# Como contribuir

Obrigado pelo interesse no AI-CryoDiag! Este projeto busca aproximar engenharia, dados e segurança operacional da realidade dos gases medicinais no SUS.

## Antes de começar

1. Leia o [README](README.md) e o [documento do projeto](docs/PROJECT.md).
2. Não envie dados de pacientes, credenciais, tokens ou telemetria real identificável.
3. Para mudanças relacionadas à segurança física ou operação hospitalar, descreva claramente as limitações e peça revisão de especialista.

## Tipos de contribuição

- Correções de documentação;
- Simuladores e dados sintéticos;
- Testes automatizados;
- Melhorias de ingestão MQTT;
- Visualizações e dashboards;
- Modelos de detecção de anomalias;
- Revisões de arquitetura e segurança.

## Fluxo recomendado

1. Abra uma issue explicando o problema ou a proposta.
2. Crie uma branch com nome descritivo, como `feature/simulador-sensores`.
3. Faça commits pequenos e claros.
4. Atualize a documentação e os testes.
5. Abra um pull request descrevendo o que mudou, como testar e quais riscos existem.

## Padrões de qualidade

- Prefira código simples e legível;
- Use dados sintéticos nos exemplos;
- Inclua tratamento de erros e logs úteis;
- Nunca coloque segredos no repositório;
- Não apresente protótipos como sistemas certificados ou prontos para uso clínico.
