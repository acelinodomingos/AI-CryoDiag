# Segurança

O AI-CryoDiag é um protótipo em desenvolvimento para pesquisa e validação. Não deve ser usado como único mecanismo de segurança em instalações hospitalares.

## Não publique

- Senhas, tokens, chaves de API ou certificados;
- Dados de pacientes ou informações pessoais;
- Endereços e credenciais de infraestrutura real;
- Telemetria identificável de uma instalação;
- Configurações que possam comprometer equipamentos.

## Como reportar uma vulnerabilidade

Não abra uma issue pública com detalhes de uma vulnerabilidade ainda não corrigida. Entre em contato com o mantenedor pelo perfil [acelinodomingos](https://github.com/acelinodomingos) descrevendo o impacto, os passos para reprodução e uma forma segura de retorno.

## Princípios

Toda implementação deve passar por revisão técnica, testes em ambiente controlado e validação de profissionais habilitados antes de qualquer uso operacional.
